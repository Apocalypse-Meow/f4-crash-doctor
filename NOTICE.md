# NOTICE — crash-signature knowledge pack provenance

The crash-signature pack shipped with F4 Crash Doctor
(`src/f4_crash_doctor/data/signatures.json`) and the calibration profile
(`src/f4_crash_doctor/data/f4_profile.json`) were **independently authored**
for this project. All descriptive text — signature names, cause explanations,
and fix guidance — was written from scratch in plain English based on public
community documentation of Fallout 4 crash behavior.

The underlying technical facts (engine symbol names such as
`LooseFileAsyncStream`, exception codes, the 255-plugin cap, the BA2 archive
limit, version-locking of F4SE and the Address Library, and so on) are
community knowledge about the game engine and are not copyrightable.

**No content was copied or derived from:**

- **CLASSIC-Fallout4** (licensed CC BY-NC 4.0) — no text, data tables, or
  code were used.
- **Phostwood/crash-analyzer** (no published license) — no text, data, or
  code were used.

Both projects, along with the resources below, are acknowledged as
references and prior art in the space of Fallout 4 crash-log analysis:

- Buffout 4 — https://www.nexusmods.com/fallout4/mods/47359
- CLASSIC — https://www.nexusmods.com/fallout4/mods/56255
- Phostwood's crash analyzer — https://github.com/Phostwood/crash-analyzer
